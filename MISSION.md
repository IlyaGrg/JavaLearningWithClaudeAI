# Mission: Java backend junior за год

## Why
К концу первого курса КАИ (лето 2027) начать рассылать резюме на позицию junior Java backend-разработчика в компании и банки Казани. Java выбрана потому, что на ней пишут в банках и крупных предприятиях и по ней много вакансий.

## Success looks like
- Сам, без ИИ, пишу backend-приложение (REST API на Spring Boot + PostgreSQL) и могу объяснить каждую строчку кода.
- На работе использую ИИ для ускорения, но понимаю и могу проверить любой код, который он сгенерировал.
- Сам «девопшу» своё приложение: Dockerfile, docker compose (приложение + БД), запуск на Linux-сервере.
- Пишу SQL руками: JOIN, GROUP BY, индексы, транзакции; проектирую простую схему БД.
- Владею Git выше среднего: ветки, merge и rebase, разрешение конфликтов, pull request, осмысленная история коммитов.
- На GitHub лежат 2–3 законченных проекта, которые не стыдно показать на собеседовании.

## Constraints
- 8–12 часов в неделю помимо учёбы; в сессию меньше.
- Стартовый уровень: Python, уверенный терминал Ubuntu, базовый Git (clone/add/push/pull); в Java пройдены условия, циклы, массивы, ArrayList, строки.
- Окружение: Ubuntu, OpenJDK 21, IntelliJ IDEA.
- Формат: подробная теория с разбором каждой строки кода → домашнее задание → код-ревью от преподавателя.

## Out of scope
- Frontend (React и т. п.), мобильная разработка, Kotlin.
- Kubernetes и облака — только после того, как уверенно работает Docker.
- Олимпиадные алгоритмы сверх того, что спрашивают на junior-собеседованиях.
