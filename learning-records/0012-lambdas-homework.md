# Лямбды и Comparator: синтаксис усвоен; проверки проходят на пустом результате

В домашке 0011 Илья работал в ветке `feature/lambdas`, сделал 7 осмысленных коммитов, слил её перемоткой и запушил. Шаг 3 сделан **в правильном порядке**: сначала коммит с проверками `balanceByOwner`/`accountsByOwner` (сумма у владельца с двумя счетами, размер групп 2 и 1 — без ошибки урока 7 «размер мапы»), потом рефакторинг через `merge(…, Integer::sum)` и `computeIfAbsent(…, k -> new ArrayList<>())`, и проверки остались ОК. Сортировки на `Comparator.comparing(...).thenComparingInt(...)` и `reversed()` возвращают новый список, `compareTo` не тронут. `findAccounts(Predicate)` написан по образцу из объяснения на `Shop`, вызывается с двумя лямбдами, строки сравниваются через `equals`. Хвосты урока 9 (`existsById` без двойного отрицания, `findAll` одной строкой) закрыты. Эксперименты 7.1–7.3 сделаны, ошибки записаны, объяснения верные.

**Evidence**: `src/lesson0011/`, коммиты 35a6e28…f9006db, c5fe540; ревью 2026-10-22, JDK 21.

**Implications**:
- **Главное — повтор паттерна «проверка не ловит баг»**: проверки `findAccounts` и `sortedByOwner` проверяют только «каждый элемент подходит / пары упорядочены». Пустой список проходит их. Я проверил: `findAccounts`, который всегда возвращает пустой список, — обе проверки ОК; `sortedByOwner`, который возвращает `new ArrayList<>()`, — ОК. Задание просило вычислить ожидание руками (кто первый, сколько счетов) — не сделано.
- **`Scanner` в проверках**: `N` вводится с клавиатуры. Проверка зависит от ввода, а без ввода программа падает с `NoSuchElementException`. Тест должен быть детерминированным — важно перед JUnit (урок 15).
- 7.3: `@FunctionalInterface` поставлен над **переменной**, а не над интерфейсом, поэтому получена другая ошибка (`annotation interface not applicable to this kind of declaration`), а ожидаемая `Unexpected @FunctionalInterface annotation` — нет. В 7.1 не записана вторая часть (со ссылкой на метод компилируется).
- Проверка «список банка не изменился после сортировки» не сделана. `findAccounts` без `public`. `sortedByBalanceDesc` через `comparing`, а не `comparingInt`.
- Git: ветка `feature/lambdas` не удалена; `origin/lesson0010-notes` до сих пор на GitHub. `git show --stat` после слияния, видимо, сделан — чужие уроки не задеты.
