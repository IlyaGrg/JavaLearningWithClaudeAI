# Передача массива в метод: ошибка с for-each исправлена

В первом черновике `applyDiscount` Илья менял цены через for-each (`price = ...`), то есть менял копию элемента, а массив не трогал. Увидев вывод до и после через `Arrays.toString`, он сам переписал цикл на индексы (`prices[i] = ...`). В комментарии правильно объяснил, почему изменения видны в `main`: метод получает ссылку на тот же массив. Перегрузку `averagePrice(int[])` / `averagePrice(ArrayList<Integer>)` применил верно.

**Evidence**: `src/lesson0001/Shop.java`, коммит a8f3f78; черновик с for-each был виден в сессии 2026-10-08.

**Implications**: в ООП-уроке объекты-параметры можно объяснять через уже понятную модель «копия ссылки». Не пропускать проверку граничных случаев: пустой массив или список и короткие строки он пока не учитывает (см. ревью 0001).

**Update (ревью исправлений)**: граничные случаи исправил сам. Поставил проверку длины перед `startsWith`, то есть понял порядок вычисления `&&`, и добавил ветку для пустого массива и списка. Рекомендация `return условие;` пока не применена, к ней вернуться.
