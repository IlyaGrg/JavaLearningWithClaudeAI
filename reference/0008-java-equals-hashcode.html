equals и hashCode

Шпаргалка к уроку 0008.

== или equals

JavaPython

Примитивы (int, double, boolean) — ==. Объекты (String, Integer, свои классы) — equals. Без переопределения Object.equals работает как ==.

Шаблон

import java.util.Objects;

@Override
public boolean equals(Object o) {                     // Object, не Money!
    if (this == o) {
        return true;
    }
    if (o == null || getClass() != o.getClass()) {    // сначала null
        return false;
    }
    Money other = (Money) o;                          // приведение типа
    return amount == other.amount                     // примитив — ==
        && Objects.equals(currency, other.currency);  // объект — equals (null-безопасно)
}

@Override
public int hashCode() {
    return Objects.hash(amount, currency);            // те же поля, что в equals
}

IntelliJ: Alt+Insert → equals() and hashCode().

Правила

  • equals и hashCode переопределяют только вместе.
  • Равны по equals → обязаны иметь равный hashCode. Обратное не требуется (коллизии допустимы).
  • equals: рефлексивен, симметричен, транзитивен, постоянен; x.equals(null) — false.
  • Изменяемые поля не включать, если объект лежит в HashSet / служит ключом HashMap.

Как ищет HashSet / HashMap

  1. hashCode() → номер корзины.
  2. equals() с каждым элементом этой корзины.

ArrayList.contains хеши не использует — только equals подряд.
