ЧастьПримерПравило
Модификаторыstatic, publicВызываешь из main → пиши static (подробнее в уроке про ООП)
Тип результатаint, boolean, String, voidvoid — метод ничего не возвращает
ИмяfindMax, isValidГлагол, camelCase, с маленькой буквы
Параметры(int[] a, int n)Тип + имя для каждого; может быть ()
Сигнатураsum(int[])Имя + типы параметров. Тип результата в неё не входит

Передача аргументов — всегда по значению

Что передалиЧто копируетсяИзменение внутри метода видно снаружи?
Примитив: int, double, boolean, char…Само значениеНет
Массив, ArrayList, объектСсылка (адрес)Изменение содержимого (a[0] = 1, list.add(x)) — да.
Присваивание нового (a = new int[3]) — нет

Перегрузка

static int    sum(int a, int b)       { ... }   // ✓
static int    sum(int[] numbers)      { ... }   // ✓ другие параметры
static double sum(double a, double b) { ... }   // ✓ другие типы
static long   sum(int a, int b)       { ... }   // ✗ отличается только результат

Ловушка: деление целых

3 / 2          // 1   — int / int = int, дробная часть отбрасывается
3 / 2.0        // 1.5
(double) 3 / 2 // 1.5 — сначала приводим к double, потом делим
