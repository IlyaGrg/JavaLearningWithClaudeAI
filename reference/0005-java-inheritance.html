Шаблон потомка

public class DiscountedProduct extends Product {      // один родитель
    private int discountPercent;                       // своё поле

    public DiscountedProduct(String name, int price, int discountPercent) {
        super(name, price);                            // первой строкой
        // проверки своих полей — после super
        this.discountPercent = discountPercent;
    }

    @Override                                          // всегда при переопределении
    public int getFinalPrice() {
        return getPrice() - getPrice() * discountPercent / 100;   // private родителя — через геттер
    }

    @Override
    public String toString() {
        return super.toString() + " (скидка " + discountPercent + "%)";   // версия родителя + своё
    }
}

Что получает потомок

У родителяВ потомке
public-методынаследуются, можно вызывать и переопределять
private-поляесть внутри объекта, но по имени недоступны → геттеры
protectedдоступны потомку напрямую (для полей — избегать)
конструкторыне наследуются → super(...)

Нет extends → неявно extends Object: отсюда toString(), equals() у всех объектов.

Полиморфизм

Product p = new DiscountedProduct("Кофе", 800, 25);
p.getFinalPrice();       // 600 — версия потомка
p.getDiscountPercent();  // ошибка компиляции
  1. Какие методы можно вызвать — по типу переменной (компилятор).
  2. Какая версия выполнится — по типу объекта (при выполнении). Работает и для вызовов внутри кода родителя.

Когда наследовать

  • Только если «Потомок — разновидность Родителя» — правда. Иначе поле (композиция).
  • Потомок не нарушает обещаний родителя.
  • final class — наследование запрещено (так сделан String).
