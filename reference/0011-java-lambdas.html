Лямбды и Comparator

Шпаргалка к уроку 0011.

Синтаксис

acc -> acc.getBalance() > 1000          // один параметр
(a, b) -> a.getOwner().compareTo(b.getOwner())
() -> new ArrayList<>()                 // без параметров
(a, b) -> { ...; return x; }             // блок: {} и return

Лямбда пишется только там, где ожидается функциональный интерфейс — ровно один абстрактный метод. @FunctionalInterface — проверка компилятором.

Comparator

list.sort(Comparator.comparing(BankAccount::getOwner));
list.sort(Comparator.comparingInt(BankAccount::getBalance).reversed());
list.sort(Comparator.comparing(BankAccount::getOwner)
                    .thenComparingInt(BankAccount::getBalance));

Comparable — один естественный порядок внутри класса. Comparator — любые порядки снаружи.

Коллекции

map.merge(key, value, Integer::sum);                      // подсчёт / сумма
map.computeIfAbsent(key, k -> new ArrayList<>()).add(x);  // группировка
list.removeIf(acc -> acc.getBalance() == 0);              // удалить по условию
list.forEach(System.out::println);                        // для каждого
