enum

public enum Currency {
    RUB("Российский рубль"), USD("Доллар США"), EUR("Евро");

    private final String displayName;
    Currency(String displayName) { this.displayName = displayName; }
    public String getDisplayName() { return displayName; }
}

record

public record AccountNumber(String value) {
    public AccountNumber {                       // компактный конструктор: только проверки
        if (value == null || !value.startsWith("BANK")) {
            throw new IllegalArgumentException("Некорректный номер: " + value);
        }
    }
}

Даёт: private final поле, конструктор, value() (без get), equals/hashCode по полям, toString → AccountNumber[value=BANK-1]. Класс final.

record — значение, неизменяемое. class — сущность, изменяемое состояние, наследование.

Optional

Optional.of(x) / empty() / ofNullable(x)создать
orElse(d)значение или d
orElseThrow(() -> new X(...))значение или исключение
map(f)преобразовать, если есть
ifPresent(c)сделать, если есть
isPresent() / isEmpty()проверить
get()пусто → NoSuchElementException: No value present; избегать

Только для возвращаемых значений. Никогда не возвращать null вместо Optional.

// как в Spring: репозиторий — Optional, сервис — исключение
public BankAccount findAccount(AccountNumber n) {
    return accounts.findById(n)
            .orElseThrow(() -> new AccountNotFoundException("Счёт не найден: " + n));
}
