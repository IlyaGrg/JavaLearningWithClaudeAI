Stream API

Шпаргалка к уроку 0012.

Конвейер

list.stream()              // источник — коллекция не меняется
    .filter(...)           // промежуточные — ленивые, сколько угодно
    .map(...)
    .toList();             // терминальная — запускает, одна, в конце

Промежуточные

filter(acc -> …)оставить подходящие (Predicate)
map(BankAccount::getOwner)превратить каждый (Function)
mapToInt(BankAccount::getBalance)в IntStream: sum, max, average
distinct()убрать повторы (по equals)
sorted() / sorted(comparator)отсортировать
limit(n)первые n

Терминальные

toList()неизменяемый список
collect(Collectors.toList())изменяемый список
collect(Collectors.toSet())множество
count()long
sum()у IntStream
anyMatch / allMatch / noneMatchboolean
max(cmp), min(cmp), findFirst()Optional
forEach(...)только для вывода, не для накопления

Группировка

.collect(Collectors.groupingBy(BankAccount::getOwner))
// Map<String, List<BankAccount>>

.collect(Collectors.groupingBy(BankAccount::getOwner,
                               Collectors.summingInt(BankAccount::getBalance)))
// Map<String, Integer>

Ловушки

ЧтоРезультат
allMatch на пустом стримеtrue — проверяй размер отдельно
вторая терминальная на том же стримеIllegalStateException: stream has already been operated upon or closed
toList().add(...)UnsupportedOperationException
нет терминальной операцииничего не выполняется (ленивость)
печать / изменение полей в filter, mapтак нельзя: без побочных эффектов

Было → стало

int sum = 0; for (BankAccount a : list) sum += a.getBalance();
→ list.stream().mapToInt(BankAccount::getBalance).sum();

Set<String> s = new HashSet<>(); for (…) s.add(a.getOwner());
→ list.stream().map(BankAccount::getOwner).collect(Collectors.toSet());

Источники: Oracle — Aggregate Operations, Stream (Java 21), Collectors. Проверено на JDK 21.
