private = доступ из кода класса, в том числе к полям других объектов того же класса.

Шаблон защищённого класса

public class Product {
    private String name;                       // поля закрыты
    private int price;

    public Product(String name, int price) {   // проверки ДО записи
        if (name == null || name.isBlank()) {  // сначала null, потом isBlank
            throw new IllegalArgumentException("Название не может быть пустым");
        }
        checkPrice(price);
        this.name = name;
        this.price = price;
    }

    public String getName() { return name; }   // геттер; сеттера нет — не меняется
    public int getPrice()   { return price; }

    public void setPrice(int price) {          // сеттер с проверкой
        checkPrice(price);
        this.price = price;
    }

    private static void checkPrice(int price) {   // одно правило — одно место
        if (price < 0) {
            throw new IllegalArgumentException("Цена не может быть отрицательной: " + price);
        }
    }
}

Чек-лист класса

  • Все поля private.
  • Конструктор проверяет всё, что проверяют сеттеры.
  • Сеттер только у тех полей, которые действительно меняются. Проверка — до присваивания.
  • Вместо setX — методы-действия, если у изменения есть правила: withdraw, sell, addStock.
  • Повторяющаяся проверка вынесена в private-метод.

Исключение

throw new IllegalArgumentException("что не так: " + значение);
  • Метод прерывается сразу, строки после throw не выполняются.
  • Не перехвачено → программа завершается и печатает стек вызовов.
  • Стек читается сверху вниз: где брошено → кто вызвал → … → main. <init> в стеке = конструктор.
