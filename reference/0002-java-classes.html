Классы и объекты

Шпаргалка к уроку 0002.

Шаблон класса

public class Product {              // файл Product.java
    String name;                     // поля: у каждого объекта свои
    int price;

    Product(String name, int price) {   // конструктор: имя класса, без типа результата
        this.name = name;                // this.поле = параметр
        this.price = price;
    }

    void printInfo() {               // метод объекта: есть this
        System.out.println(name + ": " + price);
    }

    static int sum(int a, int b) {   // метод класса: нет this
        return a + b;
    }
}

Ссылки

  • Product b = a; — копия ссылки: объект один, изменения видны через обе переменные.
  • В метод передаётся копия ссылки: изменение полей видно снаружи, p = new … — нет.
  • Вызов метода или поля у null → NullPointerException.
