pom.xml: порядок блоков

<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>ru.ilyagrg</groupId>
    <artifactId>bank</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.release>21</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.apache.commons</groupId>
            <artifactId>commons-lang3</artifactId>
            <version>3.17.0</version>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.codehaus.mojo</groupId>
                <artifactId>exec-maven-plugin</artifactId>
                <version>3.5.0</version>
                <configuration>
                    <mainClass>ru.ilyagrg.bank.Main</mainClass>
                </configuration>
            </plugin>
        </plugins>
    </build>
</project>

GAV = groupId:artifactId:version — координаты проекта. Чужие координаты копировать с central.sonatype.com. Коробки (dependencies, plugins) — одна на файл.

Структура

pom.xml
src/main/java/ru/ilyagrg/bank/*.java   ← package ru.ilyagrg.bank;
src/test/java/...                      ← тесты
target/                                ← результат, в .gitignore

Команды (из папки с pom.xml)

mvn compilesrc/main/java → target/classes
mvn testcompile + запустить тесты
mvn packagecompile + test + target/*.jar
mvn cleanудалить target/
mvn compile exec:javaсобрать и запустить mainClass
mvn -vверсии Maven и Java (должна быть 21)
-qтихо: без строк [INFO]

Фаза выполняет все предыдущие: validate → compile → test → package → verify → install.

Ошибки

release version 21 not supportedMaven взял не ту JDK → export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
Non-parseable POM ... end tag nameошибка XML: тег не закрыт или регистр
Duplicated tag: 'dependencies'второй блок-коробка вместо элемента в первой
No sources to compile + SUCCESSфайлы не в src/main/java
records are not supported in -source 8нет maven.compiler.release
Could not resolve dependenciesневерные координаты или версия
package ... does not existнет зависимости в pom.xml (или IntelliJ не обновлена)
NoClassDefFoundError при java -cp target/classesбиблиотек нет в ручном -cp → mvn exec:java
no main manifest attributeобычный jar не знает главный класс

Зависимости

Скачиваются один раз в ~/.m2/repository/<groupId папками>/<artifactId>/<version>/. IntelliJ после правки pom.xml — Load Maven Changes.

Источники: Maven in 5 Minutes, POM Reference, Build Lifecycle, Standard Directory Layout. Проверено на JDK 21, Maven 3.9.
