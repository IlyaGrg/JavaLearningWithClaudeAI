## Как учить Илью
- Язык обучения — русский.
- Теория подробно: код показывать целиком и объяснять **каждую строчку**. Потом домашнее задание.
- Весь Java-код — в `src/` (выбор Ильи), домашки — в `src/lessonNNNN/` с `package lessonNNNN;`. Сигнал: «проверь домашку NNNN». Я читаю файлы, ревьюю, исправляю, объясняю.
- Цель — писать код **без ИИ**. Не выдавать готовые решения домашек: сначала наводящий вопрос или подсказка, полное решение только если попросит после попытки.
- Знает Python, поэтому полезны аналогии «как в Python / чем отличается».
- **(2026-10-09, просьба Ильи) Теорию в HTML объяснять ЕЩЁ подробнее.** Уроки 1–2 оказались слишком сжатыми: в итоге отдельно переспрашивал про void/return в toString, static, ссылки на объекты (`copy = cart.get(0)`), компиляцию нескольких файлов. Правила для уроков:
  - каждое новое понятие: зачем → простыми словами → аналогия из жизни/Python → код с построчным разбором → «что будет, если…» → мини-проверка сразу после раздела (а не только квиз в конце);
  - трассировка памяти/выполнения по шагам («шаг 1: …, шаг 2: …») для всего, что связано со ссылками и потоком управления;
  - раздел «Частые вопросы» с ответами на вопросы, которые он, скорее всего, задаст;
  - не вводить термин без объяснения; не писать «подробно позже», если без этого непонятен текущий код;
  - его вопросы не глупые — говорить прямо, что вопрос хороший, когда он попадает в суть.
- Косметические пункты ревью давать отдельным чек-листом в конце: в сплошном тексте он их пропускает.
- Хорошо чувствует себя в терминале Ubuntu, так что можно давать CLI-шаги без разжёвывания.
- Каждая домашка — отдельный коммит в Git, чтобы Git-навык рос параллельно.
- Готов к сообществам: подсказывать, куда идти, особенно казанские события.
